# Czcionka z polskimi znakami

Aplikacja szuka czcionki automatycznie (Segoe UI na Windowsie, DejaVu Sans na
Linuksie, Arial Unicode na macOS). Jeśli w napisach brakuje polskich liter
(ą, ć, ę, ł, ń, ó, ś, ż, ź), skopiuj tutaj dowolny plik `.ttf` pod nazwą
`font.ttf`:

    assets/fonts/font.ttf

Można też wskazać czcionkę zmienną środowiskową:

    NETVIZ3D_FONT=/sciezka/do/czcionki.ttf python main.py
